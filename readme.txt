Dear Data 100- Running
Furkan Arif

Topic: my runs, recorded per kilometre.
Question: what affects my pace and energy- weather, time of day, hills?

Columns:
date - day of run
run - run number (1st,2nd,3rd...)
km - which km of the run
pace - minutes per km
heartrate - average heart rate for that km
elevation - metres climbed in that km
weather - sunny / cloudy / rainy / windy
timeofday - morning / afternoon / evening
energy - how i felt, 1 (tired) to 5 (great)
